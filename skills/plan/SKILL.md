---

사용자가 함께 적은 기능의 구현 계획을 세워줘.

`REQUIREMENTS.md`와 `DECISIONS.md`를 먼저 읽고, `PLAN.md`가 있으면 그것도 읽어. 이어지는 계획이면 기존 단계 번호를 유지해. **코드는 아직 작성하지 마.**

아래 형식으로 답해줘.

- **목표**: 이 작업이 끝나면 사용자가 할 수 있게 되는 것 한 문장
- **범위**: 이번에 하는 것 / 이번에 안 하는 것
- **변경할 파일**: 파일별로 무엇을 왜 바꾸는지
- **단계**: 각 단계가 30분 이내이고 단계마다 따로 검증할 수 있게
- **완료 기준**: 어떤 명령을 실행해서 어떤 결과가 나오면 완료인지. 지금 실행할 수 있는 명령은 계획을 보여 주기 전에 한 번 실행해서, 명령 자체가 동작하는지 확인한 결과를 함께 적어
- **위험과 대안**: 막힐 수 있는 지점과 그때의 대체 방법

계획을 보여준 뒤 내 승인을 기다려. 승인되면 계획을 `PLAN.md`에 저장하거나 갱신해. 테스트 실행 명령은 `PLAN.md` 한 곳에만 적어. 그다음 단계별로 구현하고, 단계마다 검증한 결과를 보고하고 커밋해줘.
