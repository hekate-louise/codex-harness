문서 경로는 PLAN.md의 매핑을 따르고, 매핑이 없으면 아래 기본 경로를 사용한다. 과제 지정 양식이 같은 역할이면 REQUIREMENTS.md·DECISIONS.md 대신 그 파일을 사용한다.


REQUIREMENTS.md와 기존 PLAN.md, 관련 결정만 읽는다. 없는 사실은 확인 필요로 표시한다.

- 모든 필수 요구와 첫 최소 실행 흐름·이번에 제외할 선택 범위·변경할 파일·짧게 실행·검증할 수 있는 단계·검증 명령과 기대값·주요 위험을 간결하게 작성한다.
- AGENTS.md의 시각 기준으로 확정 목표와 10분 전 제출 준비 시각을 정한다. 검증·기록을 각 구현 단위에 포함한다. PLAN.md가 없으면 같은 내용을 담은 최소 형식으로 만든다.
- 기존에 실행 가능한 기준 명령만 필요한 만큼 확인한다. 아직 없는 기능의 테스트를 억지로 실행하거나 검증 전체를 선행하지 않는다.
- 계획은 PLAN.md에 저장하고 핵심만 알린다. 사용자가 구현까지 요청했으면 재승인을 기다리지 않고 수행한다. 계획만 요청했으면 계획을 저장하고 마친다.
- 단계 완료 시 해당 상태·새 검증 결과만 갱신하고 로컬 커밋한다. 이미 확인한 사실과 전체 계획을 다시 출력하지 않는다.
