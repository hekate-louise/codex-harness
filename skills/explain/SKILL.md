문서 경로는 PLAN.md의 매핑을 따르고, 매핑이 없으면 아래 기본 경로를 사용한다. 과제 지정 양식이 같은 역할이면 REQUIREMENTS.md·DECISIONS.md 대신 그 파일을 사용한다.


이 스킬은 제출물 확정 전에만 쓴다. 이미 확정했거나 확정 뒤의 답변 단계이면 답변 생성·첨삭·실시간 코칭을 하지 않는다. 단계가 불명확하고 실제 평가 문항으로 보이면 먼저 단계만 확인한다.

코드와 REQUIREMENTS.md·DECISIONS.md·PLAN.md의 관련 근거를 읽고 5분 안에 훑을 수 있도록 정리한다.

- 입력→처리→출력 흐름을 파일·함수 이름과 함께 간단히 설명한다.
- 핵심 업무 규칙, 중요한 선택과 버린 대안, 독립 검증, 미검증·실패 조건을 실제 있는 만큼만 뽑는다. 정해진 개수를 채우려고 사례를 만들지 않는다.
- AI 제안을 사용자가 바꾸거나 거절한 사례는 기록에 있을 때만 언급한다. 기록에 없는 판단을 사용자가 했다고 쓰지 않는다.
- 이해도 질문은 최대 3개만 제시하고 모범 답안은 만들지 않는다. 확정 전 사용자가 자기 말로 답하면 코드·기록과 비교해 사실 오류만 짧게 피드백한다.

새 암기용 문서를 만들거나 기존 검증 결과를 복제하지 않는다. 사용자가 질문 연습을 원하지 않거나 제출이 임박하면 근거·한계 정리에서 마친다.
