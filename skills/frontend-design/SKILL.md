AGENTS.md의 시간 예산과 자동 조작 금지를 따른다. 사용자의 디자인 요구가 있으면 우선하고 업무 문제 해결에 필요한 화면만 만든다.

- 실제 사용자·입력·결과에 맞는 화면 구조를 먼저 고른다. 업무 화면은 핵심 입력, 결과, 오류 안내가 한 흐름에 보이게 하고 마케팅용 히어로나 불필요한 장식을 추가하지 않는다.
- 색·글자·간격은 작은 일관된 체계로 정하고 바로 구현한다. 여러 스타일 후보·와이어프레임·독창성 검토를 반복하거나 디자인 승인을 별도 관문으로 만들지 않는다.
- 한글 가독성, 명확한 버튼 이름, 단위·출처·상태, 키보드 초점, 작은 화면의 읽기 순서, 빈 상태·잘못된 입력 안내를 챙긴다. 외부 폰트·이미지·라이브러리는 실제 필요할 때만 가져온다.
- 가짜 수치·예제 데이터는 예시라고 표시한다. 업무 결과를 꾸며 보이게 하지 않는다. 애니메이션과 장식보다 핵심 정보와 오류 복구를 우선한다.
- 코드·HTTP 검증 뒤 사용자가 플랫폼 Browser에서 입력·버튼·결과를 직접 확인하도록 안내한다. 화면을 직접 보지 못했으면 시각 검증 완료라고 쓰지 않는다. 자동 클릭·입력·스크린샷 도구를 사용하지 않는다.
