# 요구사항과 근거

과제 지정 문서가 같은 역할이면 그 파일을 사용한다. 필수 항목을 임의로 줄이지 않는다. 구현 상태·검증 결과는 PLAN.md에 둔다.

## 문제와 사용 환경
- 누가 / 어떤 업무 / 현재 불편:
- 성공하면 달라지는 것:
- 실제 사용자 환경 (설치·인터넷·브라우저·배포):
- 입력 형식·규모·빈도 / 출력·사용처:
- 데이터·보안 제약:

## 요구사항
| ID | 우선순위 | 요구·기대 동작 | 출처 (문서 위치 / 담당자 답 / 가정) |
|---|---|---|---|

필수 제출 파일도 경로·내용·형식을 포함해 요구사항으로 적는다. Must는 모두 추적하고 선택 기능은 Should로 구분한다.
