---

실제 결정만 DECISIONS.md에 다음 번호로 추가한다. 소소한 구현 선택마다 기록하지 않는다.

- 결정 / 이유·요구사항 출처 / 버린 대안 / 한계·실패 조건 / PLAN.md의 검증 항목 참조를 남긴다.
- 실제 시각을 확인했을 때만 시각을 붙인다. 모르는 칸은 확인 필요로 남긴다. 예시 시각을 사실로 적지 않는다.
- 과거 결정을 바꾸면 새 항목에서 대체하는 D-번호를 참조한다. 과거의 근거를 지우거나 현재 상태·검증 수치를 덧붙이지 않는다.
- 동일 결정을 다시 요청받으면 중복 생성하지 않고 기존 항목을 안내한다. 기록 후에는 결정과 이유만 짧게 보고한다.
