# 작업 계획과 검증

## 시간 기준
- 플랫폼에서 확인한 작업 남은 시간 / 확인 시점: 확인 필요
- 작업 종료 / 전체 응시 종료: 확인 필요 / 14:00 (한국시간)
- 제출 시작 목표: 작업 종료 10분 전. 전체 종료와 서술형·준비 대기를 고려해 더 이른 시각 적용
- 서술형 30분 + 준비 대기 여유를 제외한 제출물 확정 목표: 확인 필요 (준비 지연·재시도 시 더 필요할 수 있음)
- 아래는 경과 시간 기준 권장 배분이며 실제 남은 시간에 맞춰 조정한다.

| 경과 | 단계 | 완료 기준 | 상태 |
|---|---|---|---|
| 0~20분 | 환경·문제 정의·핵심 질문 | Must 하나와 기준 입력·출력, 실행 제약 확인 | 대기 |
| 20~120분 | 핵심 기능 구현 | 20~30분 단위로 실행 가능한 결과 | 대기 |
| 120~150분 | 검증·수정 | 정상·예외·중요 오답 독립 검산 | 대기 |
| 150~170분 | 문서·이해도 점검 | 필수 문서·실행 방법·선택 이유·한계 확인 | 대기 |
| 170~180분 | 저장·제출 | 사용자가 미리보기·제출물 확정 진행 | 대기 |
